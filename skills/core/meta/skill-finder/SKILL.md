# Skill finder

Read `GLOSSARY.md` in this directory. It lists every skill visible to this session: name,
scope, status and purpose, grouped by category.

## How to use it

1. Find the category that matches your task.
2. Open the named skill's `SKILL.md` and follow it.
3. If nothing fits, say so in your notes. Do not improvise a procedure and present it as a
   skill. See `skill-authoring` for how a new one is proposed.

The glossary is generated, not hand-edited. If a skill you expect is missing, it is not
visible to this project.
